## Brand ownership

Until Alesvia is formally registered, the brand should be treated as founder-held working intellectual property.

After registration, the intended target state is:

- brand name held by the legal organization
- domain held by the legal organization
- source brand assets held in the organization repository
- public usage governed by this document
- trademark applications evaluated by counsel or a qualified IP advisor

Do not assign brand ownership informally to a personal project, unrelated Vercel scope, or unrelated product brand.

## Usage approvals

### Does not need special approval

- website navbar and footer
- favicon and app icon
- Open Graph images
- official Alesvia research covers
- partner decks created from approved templates
- one-pagers using approved lockups

### Needs review before publishing

- co-branded partner materials
- legal or funding pages using the mark
- public reports with external partner logos
- merchandise or printed materials
- any use where the logo appears beside a funder, public body, university, or commercial partner

### Not allowed

- stretching or skewing the mark
- changing the gold centerline to arbitrary colors
- using the mark as a decorative pattern without a documented system
- placing the mark on low-contrast backgrounds
- using the mark to imply endorsement by another institution

## Legal and clearance status

This identity is an original working design created for Alesvia inside this repository. It is built from simple geometric forms: an architectural A shape and a central path.

Current practical assessment:

- copyright risk appears low because the mark is original to this project and not copied from a known source
- copyright protection for simple shapes and common symbols can be thin or unavailable in many jurisdictions
- trademark risk still needs separate clearance because trademark law is about source confusion, similarity, goods/services, and market context

This is not legal advice.

Before final public launch, registration, or major partner use, run a proper clearance check.

## Clearance checklist

### Name clearance

Search exact and similar names:

- `Alesvia`
- `Alesvia Institute`
- `Alesvia Foundation`
- `Alesvia Research`
- `Alesvia Advisory`

Check:

- EUIPO eSearch plus
- TMview
- Czech Industrial Property Office trademark database
- WIPO Global Brand Database
- domain registrations
- company registers where relevant

### Logo clearance

Search visually similar marks in relevant classes and institutional contexts.

Focus on:

- A-shaped architectural marks
- portal/path symbols
- public-interest institutes
- AI governance organizations
- education and research organizations
- consulting/advisory organizations

### Likely Nice classes to review

This needs legal validation, but early screening should likely include:

- Class 9: software and digital tools, if Alesvia later releases tools
- Class 16: printed matter and publications
- Class 35: advisory, business, and organizational services
- Class 36: funding or investment-related advisory, if Advisory expands
- Class 41: education, training, publishing, events
- Class 42: technology research, AI evaluation, technical advisory
- Class 44: mental health adjacent programs, if Mind becomes service-facing
- Class 45: policy, public-interest, social, and compliance advisory contexts

## Trademark strategy

Recommended staged approach:

1. Use the current identity as a launch-ready working system.
2. Run name and logo screening before high-visibility launch.
3. Register the word mark `Alesvia` first if available.
4. Register the combined mark or symbol after visual identity stabilizes.
5. Keep proof of first use, publication dates, and asset creation history.

Word mark registration is usually more strategically important than the symbol because the name carries the core organizational identity.

## Version control

Every meaningful brand change should be committed with a clear message.

Recommended commit categories:

- `brand identity`
- `brand assets`
- `research cover system`
- `deck templates`
- `legal/clearance docs`

Avoid overwriting old assets silently. If a mark changes materially, add a new asset or document the replacement in this file.

---

## Public usage rule

Until clearance is complete, public language should avoid claiming:

- registered trademark status
- exclusive legal ownership beyond what is actually established
- official institutional status not yet legally registered

Use:

- `Alesvia`
- `Alesvia is being built as...`
- `Alesvia is a Czech-founded public-interest initiative...`

Avoid:

- `registered trademark`
- `official institute` if the legal registration is not complete
- `foundation` unless the legal form supports it
