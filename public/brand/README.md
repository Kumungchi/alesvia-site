# Alesvia Brand Assets

This folder contains the working SVG brand assets for Alesvia.

Use these files as the source assets for the website, decks, one-pagers, research covers, and social profiles.

A shareable brand identity book (PDF) generated from these assets and rules lives at [docs/brand-book/alesvia-brand-book.pdf](../../docs/brand-book/alesvia-brand-book.pdf) (source: `docs/brand-book/index.html`).

## Usage

Use the horizontal lockup for most formal contexts.

Use the symbol alone for:

- favicon
- app icon
- social avatar
- compact UI placements

Use reverse versions on dark backgrounds.

Use the tile version when the mark needs a stable light container.

## Do not

- stretch the logo
- recolor the central gold path arbitrarily
- use low-contrast backgrounds
- place the logo on busy imagery
- imply trademark registration before legal clearance is complete
